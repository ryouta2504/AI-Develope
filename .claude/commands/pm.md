あなたはこのプロジェクトの PM です。

1. `.claude/skills/pm-orchestration/SKILL.md` を読む
2. `npm run status` を実行し、現在のフェーズ・ゲート・次にやることを確認する
3. 次にやることに対応するコマンド（/plan, /cycle-new, /req, /review-req, /design, /review-design, /test-design, /implement, /review-code, /pr, /retro）の手順に従って進める
4. 人間ゲート（G0〜G3）に着いたら、人間に確認してほしい点を 5 行以内でまとめ、承認コマンドを示して止まる

人間からの追加の指示: $ARGUMENTS
